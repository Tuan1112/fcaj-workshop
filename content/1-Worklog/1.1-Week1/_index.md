### Week 1 Achievements:

* Successfully created and configured my first AWS Account, including root user security settings.
* Understood how to track and control monthly spending using **AWS Budgets**, and how to raise a support ticket through **AWS Support**.
* Learned the fundamentals of **IAM**: creating users/groups, attaching policies, and applying the principle of least privilege.
* Gained a clear understanding of **Amazon VPC** components (subnets, route tables, internet gateway) and how they form the networking foundation for AWS workloads.
* Practiced launching an **EC2 instance**, connecting to it, and deploying a simple application.
* Learned how **IAM Roles** allow an application running on EC2 to securely access other AWS services without hardcoding credentials.
* Built a clearer mental model of how AWS account, identity, network, and compute services connect together as the foundation of any cloud architecture.
